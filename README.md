# Website GMIH — GitHub Pages

## Deploy
1. Buat repository GitHub, misalnya `gmih-website`.
2. Upload seluruh isi folder ini ke branch `main`.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Simpan. URL biasanya `https://USERNAME.github.io/gmih-website/`.

Website ini memakai HTML/CSS/JS statis sehingga tidak membutuhkan server atau database untuk deployment dasar.

## Struktur
- `index.html`
- `assets/css/style.css`
- `assets/js/main.js`

Data resmi seperti alamat, kontak, jadwal, berita, logo, dan tautan media sosial masih perlu diganti dengan data GMIH yang disahkan pengelola.
